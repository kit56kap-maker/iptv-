Уменьшает область видео, добавляя чёрные полосы по краям. 0% — видео занимает всю область. Полезно на ТВ, где интерфейс может перекрывать края кадра.
Применяется к HLS (m3u8) потокам. Плеер выберет ближайшее доступное качество, не превышающее указанное. Для прямых потоков (MP4, TS) — не регулируется.
Сколько минут видео загружается вперёд. При кратковременных пропаданиях потока воспроизведение продолжится из буфера, а когда поток восстановится — буфер снова заполнится. 4 минуты — рекомендуемое значение. Большие значения требуют больше памяти (~100–200 МБ). При 0 — минимальная буферизация (как у обычных плееров).
